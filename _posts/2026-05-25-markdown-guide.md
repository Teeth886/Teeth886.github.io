本文介绍常用的 Markdown 语法，帮助你快速上手博客写作。

## 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
```

## 文本样式

- **粗体**：`**粗体**`
- *斜体*：`*斜体*`
- ~~删除线~~：`~~删除线~~`
- `行内代码`：`` `行内代码` ``

## 列表

无序列表：
- 项目一
- 项目二
  - 子项目

有序列表：
1. 第一步
2. 第二步
3. 第三步

## 代码块

```python
def hello():
    print("Hello, World!")
```

## 链接和图片

```markdown
[链接文字](https://example.com)
![图片描述](/assets/images/photo.jpg)
```

## 表格

```markdown
| 姓名 | 年龄 | 城市 |
|------|------|------|
| 张三 | 25   | 北京 |
| 李四 | 30   | 上海 |
```

## 数学公式

如果你的博客启用了 MathJax，可以写数学公式：

行内公式：`$E = mc^2$`

块级公式：

```
$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$
```
